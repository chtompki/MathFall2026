        \noindent\textbf{2.2.4} Analyze the following equation graphically.
        Sketch the vector field on the real line find all the fixed points, classify their
        stability, and sketch the graph of $x(t)$ for different initial conditions.
        Then try to find the analytical solution for $x(t)$, or state that it's impossible.
        The equation in question is:
        \[
            \dot{x} = e^{-x}\sin(x)
        \]

        \begin{solution}
            Set
            \[
                f(x)=e^{-x}\sin x.
            \]
            Because $e^{-x}>0$ for every $x\in\mathbb R$, the sign of $f(x)$ is the
            same as the sign of $\sin x$. The fixed points are therefore
            \[
                f(x_*)=0
                \quad\Longleftrightarrow\quad
                \sin x_*=0
                \quad\Longleftrightarrow\quad
                \boxed{x_*=n\pi,\qquad n\in\mathbb Z.}
            \]
            Moreover,
            \[
                \dot{x}>0 \quad\text{on }(2k\pi,(2k+1)\pi),
                \qquad
                \dot{x}<0 \quad\text{on }((2k-1)\pi,2k\pi).
            \]
            Thus a representative portion of the phase line is
            \[
                \begin{tikzpicture}[baseline=-0.5ex,>=stealth,scale=0.95]
                  \draw[->] (-5.4,0)--(5.8,0) node[right] {$x$};
                  \foreach \x/\lab in {-4.5/$-2\pi$,-2.25/$-\pi$,0/$0$,2.25/$\pi$,4.5/$2\pi$}{
                      \fill (\x,0) circle (2pt);
                      \node[below=5pt] at (\x,0) {\lab};
                  }

                  % Chevrons placed directly on the phase line indicate the flow direction.
                  \node[fill=white,inner sep=0.5pt] at (-3.375,0) {$>$};
                  \node[fill=white,inner sep=0.5pt] at (-1.125,0) {$<$};
                  \node[fill=white,inner sep=0.5pt] at ( 1.125,0) {$>$};
                  \node[fill=white,inner sep=0.5pt] at ( 3.375,0) {$<$};


                \end{tikzpicture}
            \]

            For the stability classification, differentiate:
            \[
                f'(x)=e^{-x}(\cos x-\sin x).
            \]
            At a fixed point $x_*=n\pi$,
            \[
                f'(n\pi)=(-1)^n e^{-n\pi}.
            \]
            Consequently,
            \[
                \boxed{x=2k\pi\text{ is unstable},\qquad
                x=(2k+1)\pi\text{ is asymptotically stable}.}
            \]
            All the fixed points are hyperbolic.

            Now let $x(0)=x_0$. If $x_0=n\pi$, uniqueness gives the equilibrium
            solution
            \[
                x(t)\equiv n\pi.
            \]
            If $2k\pi<x_0<(2k+1)\pi$, then $x(t)$ increases monotonically and
            \[
                \lim_{t\to-\infty}x(t)=2k\pi,
                \qquad
                \lim_{t\to\infty}x(t)=(2k+1)\pi.
            \]
            If $(2k-1)\pi<x_0<2k\pi$, then $x(t)$ decreases monotonically and
            \[
                \lim_{t\to-\infty}x(t)=2k\pi,
                \qquad
                \lim_{t\to\infty}x(t)=(2k-1)\pi.
            \]
            Thus every nonconstant orbit connects an unstable even multiple of $\pi$
            to one of the adjacent stable odd multiples. Representative solution curves
            near $x=0$ are shown below.
            \[
                \begin{tikzpicture}[>=stealth,x=0.85cm,y=0.8cm]
                  \draw[->] (-4.8,0)--(5.2,0) node[right] {$t$};
                  \draw[->] (0,-4.25)--(0,4.25) node[above] {$x(t)$};
                  % Stable equilibrium solutions are solid; the unstable one is dotted.
                  \draw[thick] (-4.7,3.14)--(5.0,3.14)
                  node[right,align=left] {$\pi$\\[-1mm]{\scriptsize stable}};
                  \draw[thick] (-4.7,-3.14)--(5.0,-3.14)
                  node[right,align=left] {$-\pi$\\[-1mm]{\scriptsize stable}};
                  \draw[very thick,dotted] (-4.7,0)--(5.0,0)
                  node[right,align=left] {$0$\\[-1mm]{\scriptsize unstable}};

                  % Representative nonconstant trajectories.
                  \draw[thick,domain=-4.5:4.8,samples=120,smooth]
                  plot (\x,{3.14/(1+exp(-0.85*\x))});
                  \draw[thick,domain=-4.5:4.8,samples=120,smooth]
                  plot (\x,{-3.14/(1+exp(-0.85*\x))});
                  \node at (3.2,1.55) {$0<x_0<\pi$};
                  \node at (3.2,-1.55) {$-\pi<x_0<0$};
                \end{tikzpicture}
            \]
            The drawn curves are qualitative sketches; they indicate the correct
            monotonicity and limiting equilibria, not an explicit formula for the
            solutions.

            For a nonconstant solution, separation of variables yields
            \[
                \frac{e^x}{\sin x}\,dx=dt.
            \]
            Hence, as long as $x(t)$ remains in the interval between the neighboring
            fixed points containing $x_0$,
            \[
                \boxed{
                    t=\int_{x_0}^{x(t)}\frac{e^u}{\sin u}\,du.
                }
            \]
            The antiderivative $\int e^x\csc x\,dx$ is not an elementary function, so
            there is no elementary closed-form expression for $x(t)$. If
            \[
                F(x)=\int^x\frac{e^u}{\sin u}\,du
            \]
            is defined on the interval containing $x_0$, then the solution may be
            written implicitly, or in inverse-function form, as
            \[
                F(x(t))-F(x_0)=t,
                \qquad
                \boxed{x(t)=F^{-1}\bigl(t+F(x_0)\bigr).}
            \]
            Together with the constant solutions $x(t)\equiv n\pi$, this describes all
            solutions.
        \end{solution}

        \noindent\textbf{2.2.7} Analyze the following equation graphically.
        Sketch the vector field on the real line find all the fixed points, classify their
        stability, and sketch the graph of $x(t)$ for different initial conditions.
        Then try to find the analytical solution for $x(t)$, or state that it's impossible.
        The equation in question is:
        \[
            \dot{x} = e^{x}-\cos(x)
        \]
        (Hint: Sketch the graphs of $e^x$ and $\cos(x)$ on the same axes, and look for
        intersections. You won't be able to find the fixed points explicitly, but you still can
        find the qualitative behaviour.)

        \begin{solution}
            Set
            \[
                f(x)=e^x-\cos x.
            \]
            Fixed points are intersections of $y=e^x$ and $y=\cos x$. For $x>0$,
            $e^x>1\geq \cos x$, while $e^0=\cos0=1$. Hence $x=0$ is the only
            nonnegative fixed point.

            For $x<0$, an intersection is possible only where $\cos x>0$. On every
            positive cosine lobe centered at $-2n\pi$, $n\geq1$, one has
            \[
                f\left(-\left(2n+\tfrac12\right)\pi\right)>0,
                \qquad f(-2n\pi)=e^{-2n\pi}-1<0,
            \]
            and
            \[
                f\left(-\left(2n-\tfrac12\right)\pi\right)>0.
            \]
            Therefore there are two fixed points on each such lobe. There is also one
            fixed point in $(-\pi/2,0)$, in addition to the fixed point at $0$.

            Write the negative fixed points as
            \[
                a_0\in\left(-\frac{\pi}{2},0\right)
            \]
            and, for $n\geq1$,
            \[
                a_n\in\left(-\left(2n+\frac12\right)\pi,-2n\pi\right),
                \qquad
                b_n\in\left(-2n\pi,-\left(2n-\frac12\right)\pi\right).
            \]
            Thus all the fixed points are
            \[
                \boxed{0,\quad a_0,\quad a_n,\quad b_n\ (n\geq1).}
            \]
            They cannot be expressed in elementary closed form. Numerically, the first
            few are
            \[
                a_0\approx-1.29270,\qquad b_1\approx-4.72129,\qquad
                a_1\approx-7.85359,\qquad b_2\approx-10.99559.
            \]

            As one moves from left to right across a positive cosine lobe, the sign of
            $f$ changes from positive to negative at $a_n$, and from negative to
            positive at $b_n$. The same positive-to-negative change occurs at $a_0$,
            whereas $f$ changes from negative to positive at $0$. A representative
            portion of the phase line is therefore
            \[
                \begin{tikzpicture}[baseline=-0.5ex,>=stealth,x=0.88cm]
                  \draw[->] (-6.0,0)--(6.1,0) node[right] {$x$};
                  \foreach \x/\lab/\kind in {
                      -5/b_2/U,-2.5/a_1/S,0/b_1/U,2.5/a_0/S,5/0/U}{
                      \fill (\x,0) circle (2pt);
                      \node[below=4pt] at (\x,0) {$\lab$};
                      \node[above=5pt] at (\x,0) {\scriptsize\kind};
                  }
                  \node[fill=white,inner sep=0.5pt] at (-3.75,0) {$>$};
                  \node[fill=white,inner sep=0.5pt] at (-1.25,0) {$<$};
                  \node[fill=white,inner sep=0.5pt] at ( 1.25,0) {$>$};
                  \node[fill=white,inner sep=0.5pt] at ( 3.75,0) {$<$};
                  \node[fill=white,inner sep=0.5pt] at ( 5.55,0) {$>$};
                \end{tikzpicture}
            \]
            Here S denotes asymptotically stable and U denotes unstable. Consequently,
            \[
                \boxed{a_n\text{ is asymptotically stable for every }n\geq0,}
            \]
            whereas
            \[
                \boxed{b_n\text{ is unstable for every }n\geq1,
                    \quad\text{and }x=0\text{ is unstable}.}
            \]
            In particular, $f'(0)=e^0+\sin0=1>0$, confirming directly that $0$ is
            unstable.

            The phase line determines all the solution behavior. Between any unstable
            fixed point and the stable fixed point immediately to its right, solutions
            increase toward that stable point. Between a stable fixed point and the
            unstable fixed point immediately to its right, solutions decrease toward
            the stable point. For example,
            \[
                \begin{aligned}
                    b_1<x_0<a_0 &: &x(t)&\nearrow a_0 &&(t\to\infty),
                    &x(t)&\to b_1 &&(t\to-\infty),\\
                    a_0<x_0<0 &: &x(t)&\searrow a_0 &&(t\to\infty),
                    &x(t)&\to0 &&(t\to-\infty).
                \end{aligned}
            \]
            Initial data at a fixed point give a constant solution. Representative
            solution curves are shown below; solid horizontal lines are stable
            equilibria and dotted horizontal lines are unstable equilibria.
            \[
                \begin{tikzpicture}[>=stealth,x=0.82cm,y=0.82cm]
                  \draw[->] (-5.2,0)--(5.4,0) node[right] {$t$};
                  \draw[->] (0,-5.05)--(0,3.6) node[above] {$x(t)$};

                  \draw[very thick,dotted] (-5.0,2.3)--(5.0,2.3)
                  node[right,align=left] {$0$\\[-1mm]{\scriptsize unstable}};
                  \draw[thick] (-5.0,0)--(5.0,0)
                  node[right,align=left] {$a_0$\\[-1mm]{\scriptsize stable}};
                  \draw[very thick,dotted] (-5.0,-3.7)--(5.0,-3.7)
                  node[right,align=left] {$b_1$\\[-1mm]{\scriptsize unstable}};

                  % Qualitative trajectories approaching a_0 from above and below.
                  \draw[thick,domain=-4.8:4.8,samples=120,smooth]
                  plot (\x,{2.3/(1+exp(0.9*\x))});
                  \draw[thick,domain=-4.8:4.8,samples=120,smooth]
                  plot (\x,{-3.7/(1+exp(0.9*\x))});

                  % Qualitative finite-time escape for initial data above zero.
                  \draw[thick,domain=-4.7:3.75,samples=120,smooth]
                  plot (\x,{2.55+0.16*exp(0.48*(\x+2.0))});
                  \draw[dashed] (4.15,2.3)--(4.15,3.45);
                  \node[above left] at (4.15,3.35) {\scriptsize $t=T$};
                  \node at (1.9,3.0) {\scriptsize $x_0>0$};
                \end{tikzpicture}
            \]
            The curves are qualitative sketches rather than exact solution formulas.
            For $x_0>0$, $f(x)>0$, so the solution increases without bound. In fact it
            reaches $+\infty$ in finite forward time because, for sufficiently large
            $x$,
            \[
                e^x-\cos x\geq \frac12e^x,
                \qquad
                \int^{\infty}\frac{dx}{e^x-\cos x}<\infty.
            \]
            Thus $x(t)\to+\infty$ as $t\uparrow T$ for some finite $T$.

            Finally, every nonconstant solution is separable:
            \[
                \frac{dx}{e^x-\cos x}=dt.
            \]
            With $x(0)=x_0$, its exact implicit form is
            \[
                \boxed{
                    t=\int_{x_0}^{x(t)}\frac{du}{e^u-\cos u}.
                }
            \]
            The antiderivative is not elementary, so no elementary explicit formula for
            $x(t)$ is available. On any interval that contains no fixed point, define
            \[
                F(x)=\int^x\frac{du}{e^u-\cos u}.
            \]
            Then the solution can equivalently be written in inverse-function form as
            \[
                \boxed{x(t)=F^{-1}\bigl(t+F(x_0)\bigr).}
            \]
            Together with the constant solutions at all the fixed points, this describes
            all solutions.
        \end{solution}

        \noindent\textbf{2.2.8} (Working backwards, from flows to equations)
        Given an equation
        \[
            \dot{x}=f(x),
        \]
        we know how to sketch the corresponding flow on the real line.
        Here you are asked to solve the opposite problem: For the phase
        portrait shown in Figure~1, find an equation that is consistent with
        it. (There are an infinite number of correct answers---and wrong ones
        too.)

        \begin{figure}[h]
            \centering
            \begin{tikzpicture}[scale=1.25, >=stealth]

                % Phase line
                \draw (-3,0) -- (4,0);

                % Flow arrows
                \draw[->, thick] (-2.8,0) -- (-2.0,0);
                \draw[->, thick] (-0.85,0) -- (-0.15,0);
                \draw[->, thick] (1.35,0) -- (0.65,0);
                \draw[->, thick] (2.25,0) -- (3.05,0);

                % Half-stable fixed point at x = -1
                \draw[fill=white, thick] (-1,0) circle (2.5pt);
                \begin{scope}
                    \clip (-1.1,-0.1) rectangle (-1,0.1);
                    \fill (-1,0) circle (2.5pt);
                \end{scope}
                \draw[thick] (-1,0) circle (2.5pt);

                % Stable fixed point at x = 0
                \fill (0,0) circle (2.5pt);

                % Unstable fixed point at x = 2
                \draw[fill=white, thick] (2,0) circle (2.5pt);

                % Labels
                \node[below=5pt] at (-1,0) {$-1$};
                \node[below=5pt] at (0,0) {$0$};
                \node[below=5pt] at (2,0) {$2$};

            \end{tikzpicture}
            \caption{}
        \end{figure}

        \begin{solution}
            The fixed points in the portrait are
            \[
                x=-1,\qquad x=0,
                \qquad\text{and}\qquad x=2.
            \]
            The arrows prescribe the following sign pattern for $f$:
            \[
                \begin{array}{c|cccc}
                    x&(-\infty,-1)&(-1,0)&(0,2)&(2,\infty)\\ \hline
                    f(x)&+&+&-&+
                \end{array}
            \]

            At $x=-1$, the sign does not change. Thus the simplest polynomial should
            have a zero of even multiplicity there; we choose the factor $(x+1)^2$.
            At both $x=0$ and $x=2$, the sign changes, so we choose simple factors $x$
            and $(x-2)$. This suggests
            \[
                f(x)=(x+1)^2x(x-2).
            \]
            Indeed, $(x+1)^2\geq0$, so away from $x=-1$ the sign of $f$ is determined
            by $x(x-2)$. Therefore
            \[
                \begin{aligned}
                    x<0 &: &x(x-2)&>0,\\
                    0<x<2 &: &x(x-2)&<0,\\
                    x>2 &: &x(x-2)&>0.
                \end{aligned}
            \]
            This gives precisely the required arrows on every interval, including the
            positive sign on both sides of $x=-1$. Hence one equation consistent with
            the portrait is
            \[
                \boxed{\dot{x}=(x+1)^2x(x-2).}
            \]

            The stability shown by this equation also agrees with the portrait:
            \begin{itemize}
                \item At $x=-1$, solutions move toward the fixed point from the left and
                away from it on the right. Thus $x=-1$ is half-stable
                (stable from the left and unstable from the right).
                \item At $x=0$, arrows point toward the fixed point from both sides, so
                $x=0$ is asymptotically stable.
                \item At $x=2$, arrows point away from the fixed point on both sides, so
                $x=2$ is unstable.
            \end{itemize}

            The answer is not unique. More generally, for any continuous function
            $g(x)>0$ on $\mathbb R$,
            \[
                \boxed{\dot{x}=g(x)(x+1)^2x(x-2)}
            \]
            has the same fixed points and the same phase portrait. One could also use
            higher odd multiplicities at $0$ or $2$, or a higher even multiplicity at
            $-1$, provided no additional zeros are introduced and the required sign
            pattern is preserved.
        \end{solution}

        \noindent\textbf{2.3.2} (Autocatalysis)
        Consider the model chemical reaction
        \[
            A+X
            \underset{k_{-1}}{\overset{k_1}{\rightleftarrows}}
            2X,
        \]
        in which one molecule of \(X\) combines with one molecule of \(A\)
        to form two molecules of \(X\). This means that the chemical \(X\)
        stimulates its own production, a process called \emph{autocatalysis}.
        This positive feedback process leads to a chain reaction, which
        eventually is limited by a ``back reaction'' in which \(2X\) returns
        to \(A+X\).

        According to the \emph{law of mass action} of chemical kinetics, the
        rate of an elementary reaction is proportional to the product of the
        concentrations of the reactants. We denote the concentrations by
        lowercase letters \(x=[X]\) and \(a=[A]\). Assume that there is an
        enormous surplus of chemical \(A\), so that its concentration \(a\)
        can be regarded as constant. Then the equation for the kinetics of
        \(x\) is
        \[
            \dot{x}=k_1ax-k_{-1}x^2,
        \]
        where \(k_1\) and \(k_{-1}\) are positive parameters called
        \emph{rate constants}.

        \begin{enumerate}[label=\alph*)]
            \item Find all the fixed points of this equation and classify
            their stability.
            \item Sketch the graph of \(x(t)\) for various initial values
            \(x_0\).
        \end{enumerate}

        \begin{solution}
            It is convenient to introduce
            \[
                r=k_1a>0,
                \qquad
                K=\frac{k_1a}{k_{-1}}>0.
            \]
            Then the equation becomes the logistic equation
            \[
                \dot{x}=rx\left(1-\frac{x}{K}\right).
            \]

            \begin{enumerate}[label=\alph*)]
                \item The fixed points satisfy
                \[
                    rx\left(1-\frac{x}{K}\right)=0.
                \]
                Therefore
                \[
                    \boxed{x_1^*=0,
                        \qquad
                        x_2^*=K=\frac{k_1a}{k_{-1}}.}
                \]
                Let
                \[
                    f(x)=k_1ax-k_{-1}x^2.
                \]
                Its derivative is
                \[
                    f'(x)=k_1a-2k_{-1}x.
                \]
                At the fixed points,
                \[
                    f'(0)=k_1a>0,
                    \qquad
                    f'(K)=k_1a-2k_{-1}\frac{k_1a}{k_{-1}}
                    =-k_1a<0.
                \]
                Hence
                \[
                    \boxed{x=0\text{ is unstable},
                        \qquad
                        x=K\text{ is asymptotically stable}.}
                \]
                The corresponding phase line is
                \[
                    \begin{tikzpicture}[baseline=-0.5ex,>=stealth,x=1.15cm]
                  \draw[->] (-3.1,0)--(4.4,0) node[right] {$x$};
                  \draw[fill=white,thick] (0,0) circle (2.5pt);
                  \fill (3,0) circle (2.5pt);
                  \node[below=5pt] at (0,0) {$0$};
                  \node[below=5pt] at (3,0) {$K$};
                  \node[above=5pt] at (0,0) {\scriptsize unstable};
                  \node[above=5pt] at (3,0) {\scriptsize stable};
                  \node[fill=white,inner sep=0.5pt] at (-1.5,0) {$<$};
                  \node[fill=white,inner sep=0.5pt] at ( 1.5,0) {$>$};
                  \node[fill=white,inner sep=0.5pt] at ( 3.7,0) {$<$};
                    \end{tikzpicture}
                \]
                Only $x\geq0$ is physically meaningful because $x$ is a concentration.
                On this physical domain, solutions move away from $0$ and toward $K$.

                \item Let $x(0)=x_0$. The qualitative behavior is as follows:
                \[
                    \begin{array}{c|c}
                        \text{Initial value}&\text{Behavior as }t\to\infty\\ \hline
                        x_0=0&x(t)\equiv0,\\
                        0<x_0<K&x(t)\text{ increases monotonically to }K,\\
                        x_0=K&x(t)\equiv K,\\
                        x_0>K&x(t)\text{ decreases monotonically to }K.
                    \end{array}
                \]
                Representative solution curves are shown below. The stable equilibrium is
                solid and the unstable equilibrium is dotted.
                \[
                    \begin{tikzpicture}[>=stealth,x=0.86cm,y=0.88cm]
                  \draw[->] (-4.8,0)--(5.2,0) node[right] {$t$};
                  \draw[->] (0,-0.5)--(0,5.2) node[above] {$x(t)$};

                  \draw[very thick,dotted] (-4.6,0)--(5.0,0)
                  node[right,align=left] {$0$\\[-1mm]{\scriptsize unstable}};
                  \draw[thick] (-4.6,3.1)--(5.0,3.1)
                  node[right,align=left] {$K$\\[-1mm]{\scriptsize stable}};

                  % Solutions with 0<x_0<K.
                  \draw[thick,domain=-4.5:4.8,samples=120,smooth]
                  plot (\x,{3.1/(1+2.5*exp(-0.8*\x))});
                  \draw[thick,domain=-4.5:4.8,samples=120,smooth]
                  plot (\x,{3.1/(1+0.75*exp(-0.8*\x))});

                  % Solutions with x_0>K.
                  \draw[thick,domain=-0.7:4.8,samples=120,smooth]
                  plot (\x,{3.1/(1-0.28*exp(-0.8*\x))});
                  \node at (2.7,4.1) {\scriptsize $x_0>K$};
                  \node at (2.7,1.55) {\scriptsize $0<x_0<K$};
                    \end{tikzpicture}
                \]

                For completeness, the equation can also be solved analytically. Separating
                variables gives
                \[
                    \frac{dx}{x(1-x/K)}=r\,dt.
                \]
                Since
                \[
                    \frac{1}{x(1-x/K)}=\frac1x+\frac{1}{K-x},
                \]
                integration yields
                \[
                    \ln\left|\frac{x}{K-x}\right|=rt+C.
                \]
                For $x_0\ne0$, solving for $x(t)$ gives
                \[
                    \boxed{
                        x(t)=\frac{K}{1+\left(\dfrac{K}{x_0}-1\right)e^{-rt}}
                        =\frac{\dfrac{k_1a}{k_{-1}}}
                        {1+\left(\dfrac{k_1a}{k_{-1}x_0}-1\right)e^{-k_1at}}.
                    }
                \]
                The case $x_0=0$ must be included separately and gives $x(t)\equiv0$.

                Mathematically, if $x_0<0$, then $\dot{x}<0$ and the solution decreases
                toward $-\infty$ in finite forward time. Such solutions are not chemically
                meaningful, since a concentration cannot be negative.
            \end{enumerate}
        \end{solution}

        \noindent\textbf{2.3.3} (Tumor growth)
        The growth of cancerous tumors can be modeled by the Gompertz law
        \[
            \dot{N}=-aN\ln(bN),
        \]
        where \(N(t)\) is proportional to the number of cells in the tumor,
        and \(a,b>0\) are parameters.

        \begin{enumerate}[label=\alph*)]
            \item Interpret \(a\) and \(b\) biologically.
            \item Sketch the vector field and graph \(N(t)\) for various
            initial values.
        \end{enumerate}

        The predictions of this simple model agree surprisingly well with
        data on tumor growth, as long as \(N\) is not too small; see
        Aroesty et al.\ (1973) and Newton (1980) for examples.

        \begin{solution}
            Because $N$ represents tumor size, the physically meaningful domain is
            $N\geq0$. The displayed differential equation is defined for $N>0$; since
            \[
                \lim_{N\to0^+}N\ln(bN)=0,
            \]
            we may continuously extend its right-hand side by defining $\dot N=0$ at
            $N=0$.

            \begin{enumerate}[label=\alph*)]
                \item Introduce the limiting tumor size
                \[
                    K=\frac1b.
                \]
                Then the Gompertz law can be written as
                \[
                    \dot N=aN\ln\left(\frac{K}{N}\right).
                \]
                The parameter $b$ therefore determines the saturation size, or carrying
                capacity,
                \[
                    \boxed{N_\infty=K=\frac1b.}
                \]
                Thus increasing $b$ decreases the predicted limiting tumor size.

                The per-capita growth rate is
                \[
                    \frac{\dot N}{N}=a\ln\left(\frac{K}{N}\right).
                \]
                Hence $a$ sets the time scale on which the tumor approaches its limiting
                size. In fact, as shown below, the logarithmic distance from the limiting
                size decays like $e^{-at}$, so the characteristic time is
                \[
                    \boxed{\tau=\frac1a.}
                \]
                Larger $a$ means faster growth and faster relaxation toward $K$.

                \item For $N>0$, let
                \[
                    f(N)=-aN\ln(bN)=aN\ln\left(\frac{K}{N}\right).
                \]
                The fixed points on the extended physical domain are
                \[
                    \boxed{N^*_1=0,
                        \qquad
                        N^*_2=K=\frac1b.}
                \]
                For $0<N<K$, one has $\ln(K/N)>0$, so $\dot N>0$. For $N>K$,
                $\ln(K/N)<0$, so $\dot N<0$. The phase line is therefore
                \[
                    \begin{tikzpicture}[baseline=-0.5ex,>=stealth,x=1.25cm]
                  \draw[->] (-0.35,0)--(5.1,0) node[right] {$N$};
                  \draw[fill=white,thick] (0,0) circle (2.5pt);
                  \fill (3.4,0) circle (2.5pt);
                  \node[below=5pt] at (0,0) {$0$};
                  \node[below=5pt] at (3.4,0) {$K=1/b$};
                  \node[above=5pt] at (0,0) {\scriptsize unstable};
                  \node[above=5pt] at (3.4,0) {\scriptsize stable};
                  \node[fill=white,inner sep=0.5pt] at (1.7,0) {$>$};
                  \node[fill=white,inner sep=0.5pt] at (4.25,0) {$<$};
                    \end{tikzpicture}
                \]
                Thus $N=0$ is unstable from the physically relevant side, while $N=K$ is
                asymptotically stable. In particular,
                \[
                    \boxed{
                        \begin{array}{ll}
                            0<N_0<K &: N(t)\text{ increases toward }K,\\
                            N_0=K &: N(t)\equiv K,\\
                            N_0>K &: N(t)\text{ decreases toward }K.
                        \end{array}}
                \]
                Also, under the continuous extension at the origin, $N_0=0$ gives
                $N(t)\equiv0$.

                Representative solution curves are shown below. The unstable equilibrium
                is dotted and the stable equilibrium is solid.
                \[
                    \begin{tikzpicture}[>=stealth,x=0.83cm,y=0.82cm]
                  \draw[->] (-4.8,0)--(5.3,0) node[right] {$t$};
                  \draw[->] (0,-0.45)--(0,5.7) node[above] {$N(t)$};

                  \draw[very thick,dotted] (-4.6,0)--(5.0,0)
                  node[right,align=left] {$0$\\[-1mm]{\scriptsize unstable}};
                  \draw[thick] (-4.6,3.1)--(5.0,3.1)
                  node[right,align=left] {$K=1/b$\\[-1mm]{\scriptsize stable}};

                  % Exact Gompertz profiles after scaling K=3.1 and a=0.75.
                  \draw[thick,domain=-4.5:4.8,samples=140,smooth]
                  plot (\x,{3.1*exp(-0.45*exp(-0.75*\x))});
                  \draw[thick,domain=-3.0:4.8,samples=140,smooth]
                  plot (\x,{3.1*exp(-1.25*exp(-0.75*\x))});
                  \draw[thick,domain=-0.5:4.8,samples=120,smooth]
                  plot (\x,{3.1*exp(0.32*exp(-0.75*\x))});

                  \node at (2.7,4.15) {\scriptsize $N_0>K$};
                  \node at (2.6,1.55) {\scriptsize $0<N_0<K$};
                    \end{tikzpicture}
                \]

                The solution can be found explicitly. Set
                \[
                    y(t)=\ln(bN(t)).
                \]
                For $N(t)>0$,
                \[
                    \dot y=\frac{\dot N}{N}=-a\ln(bN)=-ay.
                \]
                Therefore
                \[
                    y(t)=y(0)e^{-at}=\ln(bN_0)e^{-at}.
                \]
                Exponentiating gives
                \[
                    \boxed{
                        N(t)=\frac1b
                        \exp\left(\ln(bN_0)e^{-at}\right),
                        \qquad N_0>0.
                    }
                \]
                Equivalently,
                \[
                    N(t)=K\exp\left(\ln\left(\frac{N_0}{K}\right)e^{-at}\right).
                \]
                This formula shows directly that $N(t)\to K=1/b$ as $t\to\infty$ for
                every $N_0>0$.

                For a growing solution, the curvature changes sign when $N=K/e$. Thus a
                solution starting below $K/e$ is initially concave upward and later concave
                downward, giving the characteristic sigmoidal Gompertz growth curve. If
                $K/e\leq N_0<K$, it is concave downward for all $t\geq0$.
            \end{enumerate}
        \end{solution}

        \noindent\textbf{2.3.5} (Dominance of the fittest) Suppose $X$ and $Y$ are two species
        that reproduce exponentially fast: $\dot{X} = aX$ and $\dot{Y} = bY$, respectively, with
        initial conditions $X_0,Y_0 > 0$ and growth rates $a\ge b\ge 0$.
        Here $X$ is ``fitter'' than $Y$ in the sense that it reproduces faster, as reflected by
        the inequality $a > b$.
        So we'd expect $X$ to keep increasing its share of the total population $X + Y$ as
        $t\rightarrow\infty$.
        The goal of this exercise is to demonstrate this intuitive result, first analytically and
        then geometrically.
        \begin{itemize}
            \item[(a)] Let $x(t) = X(t)/[X(t) + Y(t)]$ denote $X$'s share of the total population.
            By solving for $X(t)$ and $Y(t)$, show that $x(t)$ increasing monotonically approaches
            1 as $t\rightarrow\infty$.
            \item[(b)] Alternatively, we can arrive at the same conclusions by deriving a differential
            equation for $x(t)$.
            To do so, take the time derivative of $x(t) = X(t)/[X(t) + Y(t)]$ using the quotient and
            chain rules.
            Then substitute for $X$ and $Y$ and therby show that $x(t)$ obeys the logistic equation
            $\dot{x} = (a - b)x(1 - x)$.
            Explain why this implies that $x(t)$ increases monotonically and approaches 1 as
            $t\rightarrow\infty$.
        \end{itemize}

        \begin{solution}
            \begin{itemize}
                \item[(a)] The equations for the two populations are independent
                exponential-growth equations. Their solutions are
                \[
                    X(t)=X_0e^{at},
                    \qquad
                    Y(t)=Y_0e^{bt}.
                \]
                Consequently,
                \begin{align*}
                    x(t)
                    &=\frac{X_0e^{at}}{X_0e^{at}+Y_0e^{bt}}\\
                    &=\frac{1}{1+\dfrac{Y_0}{X_0}e^{-(a-b)t}}.
                \end{align*}
                Since \(X_0,Y_0>0\), we have
                \[
                    0<x(t)<1
                \]
                for every finite \(t\). Moreover, because \(a>b\), the function
                \(e^{-(a-b)t}\) decreases strictly as \(t\) increases. Therefore, the
                denominator
                \[
                    1+\frac{Y_0}{X_0}e^{-(a-b)t}
                \]
                decreases strictly, so \(x(t)\) increases strictly.

                Finally, \(a-b>0\), and hence
                \[
                    \lim_{t\to\infty}e^{-(a-b)t}=0.
                \]
                It follows that
                \[
                    \boxed{\lim_{t\to\infty}x(t)=1.}
                \]
                Thus, the fitter species \(X\) monotonically increases its share of
                the total population, and its share approaches \(100\%\).

                \item[(b)] Applying the quotient rule gives
                \begin{align*}
                    \dot{x}
                    &=\frac{\dot{X}(X+Y)-X(\dot{X}+\dot{Y})}
                    {(X+Y)^2}\\
                    &=\frac{\dot{X}Y-X\dot{Y}}{(X+Y)^2}.
                \end{align*}
                Substituting \(\dot{X}=aX\) and \(\dot{Y}=bY\), we obtain
                \[
                    \dot{x}
                    =\frac{aXY-bXY}{(X+Y)^2}
                    =(a-b)\frac{XY}{(X+Y)^2}.
                \]
                From the definition of \(x\),
                \[
                    x=\frac{X}{X+Y}
                    \qquad\text{and}\qquad
                    1-x=\frac{Y}{X+Y}.
                \]
                Therefore,
                \[
                    x(1-x)
                    =\frac{X}{X+Y}\frac{Y}{X+Y}
                    =\frac{XY}{(X+Y)^2}.
                \]
                Substitution yields the logistic equation
                \[
                    \boxed{\dot{x}=(a-b)x(1-x).}
                \]

                Because \(X,Y>0\), the population share satisfies \(0<x<1\).
                Since \(a-b>0\), it follows that
                \[
                    \dot{x}=(a-b)x(1-x)>0
                    \qquad\text{whenever }0<x<1.
                \]
                Thus, \(x(t)\) increases strictly and is bounded above by \(1\), so it
                must approach a limit \(L\leq 1\). The equilibria of the logistic
                equation are determined by
                \[
                    (a-b)L(1-L)=0,
                \]
                giving \(L=0\) or \(L=1\). Since \(x(t)>0\) and is increasing, it
                cannot approach \(0\). Hence,
                \[
                    \boxed{\lim_{t\to\infty}x(t)=1.}
                \]

                Geometrically, the phase line for \(0<x<1\) points to the right because
                \(\dot{x}>0\). Therefore, every solution beginning in this interval
                moves monotonically toward the stable equilibrium \(x=1\).
            \end{itemize}

        \end{solution}

        \noindent\textbf{2.4.3} Use linear stability analysis to classify the fixed points
        of the following system.
        If linear stability analysis fails because $f'(x^*)=0$, use a graphical argument to decide
        the stability.
        \[
            \dot{x} = \tan(x)
        \]

        \begin{solution}
            Let
            \[
                f(x)=\tan(x).
            \]
            The fixed points \(x^*\) satisfy
            \[
                f(x^*)=0.
            \]
            Since
            \[
                \tan(x)=0
                \quad\Longleftrightarrow\quad
                x=n\pi,
                \qquad n\in\mathbb{Z},
            \]
            the system has the fixed points
            \[
                \boxed{x_n^*=n\pi,\qquad n\in\mathbb{Z}.}
            \]

            To classify them, we compute
            \[
                f'(x)=\sec^2(x).
            \]
            At each fixed point,
            \[
                f'(x_n^*)
                =\sec^2(n\pi)
                =1>0.
            \]
            For a one-dimensional autonomous system, a fixed point is unstable when
            \(f'(x^*)>0\). Therefore, every fixed point \(x_n^*=n\pi\) is unstable:
            \[
                \boxed{\text{Every fixed point }x_n^*=n\pi\text{ is unstable.}}
            \]

            To see this directly, consider a small perturbation
            \[
                x=n\pi+\eta.
            \]
            The linearized equation is
            \[
                \dot{\eta}=f'(n\pi)\eta=\eta,
            \]
            whose solution is
            \[
                \eta(t)=\eta(0)e^t.
            \]
            Thus, any nonzero perturbation grows exponentially, causing the solution
            to move away from \(n\pi\).

            This classification is also evident from the phase line. Immediately to
            the left of \(n\pi\),
            \[
                \tan(x)<0,
            \]
            so solutions move to the left. Immediately to the right of \(n\pi\),
            \[
                \tan(x)>0,
            \]
            so solutions move to the right. Hence, the arrows point away from each
            fixed point:
            \[
                \longleftarrow\quad n\pi\quad\longrightarrow
            \]
            confirming that every \(n\pi\) is a repelling, unstable fixed point.

            The points
            \[
                x=\frac{\pi}{2}+n\pi,
                \qquad n\in\mathbb{Z},
            \]
            are not fixed points; they are singularities at which \(\tan(x)\) and the
            differential equation are undefined.

        \end{solution}

        \noindent\textbf{2.4.8} using linear stability analysis, classify the fixed points of the
        Gompertz model of tumor growth $\dot{N} = -aN\ln(bN)$.
        (Similar to Exercise 2.3.3, $N(t)$ is proportional to the number of cells in the tumor and
        $a,b > 0$ are parameters.)

        \begin{solution}

            Let
            \[
                f(N)=-aN\ln(bN).
            \]
            For \(N>0\), a fixed point \(N^*\) satisfies
            \[
                -aN^*\ln(bN^*)=0.
            \]
            Since \(a>0\) and \(N^*>0\), this requires
            \[
                \ln(bN^*)=0.
            \]
            Therefore,
            \[
                bN^*=1,
            \]
            and the positive fixed point is
            \[
                \boxed{N^*=\frac{1}{b}.}
            \]

            To determine its stability, differentiate \(f\):
            \begin{align*}
                f'(N)
                &=-a\frac{d}{dN}\bigl[N\ln(bN)\bigr] \\
                &=-a\bigl[\ln(bN)+1\bigr].
            \end{align*}
            At \(N^*=1/b\),
            \[
                f'\left(\frac{1}{b}\right)
                =-a\left[\ln(1)+1\right]
                =-a<0.
            \]
            Thus, linear stability analysis shows that
            \[
                \boxed{N^*=\frac{1}{b}\text{ is asymptotically stable}.}
            \]

            Indeed, if \(N=1/b+\eta\), where \(\eta\) is a small perturbation, then
            the linearized equation is
            \[
                \dot{\eta}
                =f'\left(\frac{1}{b}\right)\eta
                =-a\eta.
            \]
            Its solution is
            \[
                \eta(t)=\eta(0)e^{-at},
            \]
            so perturbations decay exponentially.

            There is a minor issue at \(N=0\), since \(\ln(bN)\) is not defined
            there. However,
            \[
                \lim_{N\to0^+}N\ln(bN)=0,
            \]
            so the vector field can be continuously extended by defining \(f(0)=0\).
            Under this biologically natural extension, \(N=0\) is also a fixed point.

            Linear stability analysis cannot be applied at \(N=0\), because
            \[
                f'(N)=-a\bigl[\ln(bN)+1\bigr]\longrightarrow+\infty
                \qquad\text{as }N\to0^+.
            \]
            Instead, consider the sign of \(f(N)\). For
            \[
                0<N<\frac{1}{b},
            \]
            we have \(0<bN<1\), so \(\ln(bN)<0\). Consequently,
            \[
                \dot{N}=-aN\ln(bN)>0.
            \]
            Thus, every sufficiently small positive population moves away from
            \(N=0\). Hence,
            \[
                \boxed{N^*=0\text{ is unstable from the biologically relevant side }
                N>0.}
            \]

            The phase line is therefore
            \[
                0\quad\longrightarrow\quad \frac{1}{b}
                \quad\longleftarrow,
            \]
            because
            \[
                \dot{N}
                \begin{cases}
                    >0, & 0<N<1/b,\\
                    <0, & N>1/b.
                \end{cases}
            \]
            Thus, all positive solutions move toward the stable tumor size
            \(N=1/b\).

        \end{solution}

        \noindent\textbf{2.8.2} Sketch the slope field for the following differential equations.
        Then ``integrate'' the equation manually by drawing trajectories that are everywhere
        parallel to the local slope.
        \begin{itemize}
            \item[(a)] $\dot{x} = x$
            \item[(c)] $\dot{x} = 1 - 4x(1 - x)$
        \end{itemize}

        \begin{solution}
            In each plot, $t$ is the horizontal coordinate and $x$ is the vertical
            coordinate. Because both equations are autonomous, the slope depends only
            on $x$. Thus all line elements on a given horizontal line have the same
            slope.

            \begin{itemize}
                \item[(a)] Here the local slope is
                \[
                    \frac{dx}{dt}=x.
                \]
                The slope is zero on $x=0$, positive above $x=0$, and negative below it.
                Its magnitude increases as $|x|$ increases. Separating variables (away
                from $x=0$) gives
                \[
                    \frac{dx}{x}=dt,
                    \qquad \ln|x|=t+C,
                \]
                so the trajectories are
                \[
                    \boxed{x(t)=Ce^t}, \qquad C\in\mathbb{R}.
                \]
                The case $C=0$ is the equilibrium solution $x(t)=0$. If $C>0$, the
                trajectory rises exponentially as $t$ increases; if $C<0$, it falls
                farther below zero. Hence $x^*=0$ is an unstable equilibrium. These
                exponential curves are tangent to the corresponding line elements of the
                slope field at every point.

                \item[(c)] First simplify the vector field:
                \[
                    \frac{dx}{dt}=1-4x(1-x)=4x^2-4x+1=(2x-1)^2
                    =4\left(x-\frac12\right)^2.
                \]
                Therefore the slope is nonnegative everywhere and vanishes only on
                $x=\tfrac12$. The horizontal line
                \[
                    \boxed{x(t)=\frac12}
                \]
                is an equilibrium trajectory. All other trajectories increase with $t$.
                The slope becomes flatter near $x=\tfrac12$ and steeper farther away.

                For a non-equilibrium solution, set $y=x-\tfrac12$. Then
                \[
                    \dot y=4y^2,
                    \qquad \frac{dy}{y^2}=4\,dt.
                \]
                Integration yields
                \[
                    -\frac1y=4t+C,
                \]
                or, in terms of an initial condition $x(t_0)=x_0\ne\tfrac12$,
                \[
                    \boxed{
                        x(t)=\frac12+
                        \frac{x_0-\frac12}{1-4\left(x_0-\frac12\right)(t-t_0)} }.
                \]
                If $x_0<\tfrac12$, the solution increases toward $\tfrac12$ as
                $t\to\infty$. If $x_0>\tfrac12$, it increases away from the equilibrium
                and becomes unbounded at the finite time
                \[
                    t=t_0+\frac{1}{4(x_0-\frac12)}.
                \]
                Thus $x^*=\tfrac12$ attracts trajectories from below but repels them from
                above: it is \emph{semistable}. The phase-line arrows point upward on
                both sides of $x=\tfrac12$.
            \end{itemize}

        \noindent\textbf{2.8.6} (Analytically intractible problem) Consider the initial value
        problem $\dot{x} = x + e^{-x}$, $x(0) = 0$.
        \begin{itemize}
            \item[(a)] Sketch the solution $x(t)$ for $t\ge 0$
            \item[(b)] Using some analytical arguments, obtain rigorous bounds on the value of $x$ at
            $t=1$.
            In other words profe that $a < x(1) < b$, for $a,b$ to be determined.
            By being clever, try to make $a$ and $b$ as close together as possible.
            (Hint: Bound the given vector field by approximate vector fields that can be integrated
            analytically.)
            \item[(c)] Now for the numerical part: Using the Euler method, compute $x$ at $t=1$, correct
            to three decimal places.
            How small does the stepsize need to be to obtain the desired accuracy?
            (Give the order of magnitude, not the exact number)
        \end{itemize}

        \begin{solution}
            Write $f(x)=x+e^{-x}$. Since $f(x)>0$ for every $x$, the solution is
            strictly increasing. Also
            \[
                \ddot{x}=f'(x)\dot{x}=(1-e^{-x})(x+e^{-x}).
            \]
            For $t>0$ we have $x(t)>0$, so $1-e^{-x(t)}>0$ and consequently
            $\ddot{x}(t)>0$. Thus the solution starts at the origin with slope
            $\dot{x}(0)=1$, and is increasing and concave upward. This determines the
            qualitative sketch in part (a).

            For rigorous bounds, the alternating Taylor estimates, valid for $x\geq0$,
            give
            \[
                1-x\leq e^{-x}\leq 1-x+\frac{x^2}{2}.
            \]
            It follows first that $\dot{x}\geq1$, hence $x(t)\geq t$. The upper
            inequality gives
            \[
                \dot{x}\leq1+\frac{x^2}{2}.
            \]
            Let $u$ solve $u'=1+u^2/2$, $u(0)=0$. Scalar comparison and direct
            integration yield
            \[
                x(t)\leq u(t)=\sqrt2\tan\left(\frac{t}{\sqrt2}\right).
            \]
            In particular, on $0\leq t\leq1$,
            \[
                x(t)\leq U:=\sqrt2\tan\left(\frac1{\sqrt2}\right)
                \approx1.208460243.
            \]

            We can sharpen the lower bound using one more Taylor term:
            \[
                e^{-x}\geq1-x+\frac{x^2}{2}-\frac{x^3}{6}.
            \]
            Because $0\leq x(t)\leq U$ for $0\leq t\leq1$, we have $x^3\leq Ux^2$.
            Therefore
            \[
                \dot{x}\geq1+cx^2,
                \qquad c:=\frac12-\frac{U}{6}>0.
            \]
            If $\ell'=1+c\ell^2$ and $\ell(0)=0$, comparison gives
            \[
                x(t)\geq\ell(t)=\frac{1}{\sqrt c}\tan(\sqrt c\,t).
            \]
            At $t=1$ this produces the rigorous bracket
            \[
                \boxed{
                    1.113051909
                    <x(1)<
                    1.208460243 }.
            \]
            Strict inequalities hold for $t>0$ because the relevant Taylor bounds are
            strict away from $x=0$.

            For part (c), explicit Euler uses
            \[
                x_{n+1}=x_n+h\bigl(x_n+e^{-x_n}\bigr),
                \qquad x_0=0,qquad h=\frac1N.
            \]
            A high-accuracy computation gives
            \[
                x(1)\approx1.1536390027,
            \]
            and therefore, to three decimal places,
            \[
                \boxed{x(1)=1.154.}
            \]
            Euler's method has global error $O(h)$. Numerically, the error is about
            $0.2825h$ for small $h$, so an absolute error below $5\times10^{-4}$
            requires $h$ on the order of $10^{-3}$. Because the exact value lies fairly
            close to the rounding boundary $1.1535$, obtaining the displayed rounded
            value $1.154$ reliably requires a somewhat smaller step, approximately
            $h\lesssim4\times10^{-4}$ (a few times $10^{-4}$).
